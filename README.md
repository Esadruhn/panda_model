# panda_model

[Large-scale pancreatic cancer detection via non-contrast CT and deep learning](https://www.nature.com/articles/s41591-023-02640-w)

## Datasets

[Pancreas CT dataset](https://doi.org/10.7937/K9/TCIA.2016.tNB1kqBU): 82 subjects, abdominal contrast enhanced 3D CT scans from healthy subjects (no cancer), with ground truth for pancreas segmentation.
